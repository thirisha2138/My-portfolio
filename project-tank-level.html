warning

The Challenge

Manual residential or industrial water tank systems suffer from systemic reliability failures caused by a complete lack of internal telemetry, typically resulting in:

  • Water overflow accidents causing structural damage and significant water waste.
  • Pump dry running introducing massive heat damage and burning out motor coils.
  • No real-time monitoring requiring physical intervention and constant checking.
  • Inefficient water usage driven by asynchronous timing loops.

arrow_forward Core problem: How can we intelligently automate fluid level monitoring and instantly drive pump control hardware?

ultrasonic_core.ino 
long duration;
int distance;

digitalWrite(trigPin, LOW);
delayMicroseconds(2);
digitalWrite(trigPin, HIGH);
delayMicroseconds(10);
digitalWrite(trigPin, LOW);

// Calculate Distance via speed of sound metrics
duration = pulseIn(echoPin, HIGH);
distance = duration * 0.034 / 2;

if (distance > threshold_low) {
    digitalWrite(relayPin, HIGH); // Pump ON
} else if (distance < threshold_high) {
    digitalWrite(relayPin, LOW);  // Pump OFF
}
