warning

The Challenge

Traditional agricultural methodologies heavily rely on pre-set schedules or completely manual watering interventions. This causes significant constraints on yields and resources:

  • Water wastage from over-irrigating saturated lands.
  • Manual monitoring requirements which are non-scalable over large fields.
  • Inefficient irrigation timing disregarding daily heat-evaporation metrics.
  • Inconsistent crop growth due to harsh fluctuations between drought and inundation.

arrow_forward Core problem: How can we completely automate watering behaviors to intelligently trigger only based on real-time sub-surface soil saturation conditions?

Hardware Integration

sensors

Moisture Probe

Measures water saturation through varying volumetric resistance. Feeds raw analog pulse data back to ADC inputs.

toggle_on

5V Relay Module

Acts as a physical high-duty switch closing the power loop between the heavy active water pump and battery load.

developer_board

Arduino Brain

The centralized ATmega328P processor calibrating and running logic thresholds off defined moisture coefficients.

irrigation_logic.ino 
const int relayPin = 2;
const int moisturePin = A0;
const int moistureThreshold = 500;

void loop() {
  int moistureLevel = analogRead(moisturePin);

  if (moistureLevel > moistureThreshold) {
    digitalWrite(relayPin, HIGH); // Pump ON (Dry soil)
    delay(5000);
    digitalWrite(relayPin, LOW);  // Pump OFF
  }

  delay(1000);
}
