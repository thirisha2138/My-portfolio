warning

The Challenge

Children with autism often face profound communication challenges resulting in difficulties maintaining shared attention and recognizing underlying social cues. Compounding these hurdles:

  • Continuous Monitoring Needs: Parents and therapists require non-stop assessment which is incredibly taxing.
  • Lack of Personalized Tools: Standard systems lack continuous, emotionally-aware interaction loops.
  • Inclusivity Bottlenecks: Historically, therapy robots suffer from heavy neurotypical design bias and high cost boundaries.

arrow_forward Core problem: How can we develop an intelligent companion capable of sensing emotion, adjusting interactions dynamically, and delivering personalized therapy feedback autonomously?

emotion_adaptive_handler.py 
def process_therapy_loop(frame, audio_input):
    # 1. Multimodal Perception Inference
    facial_landmarks = realsense_tracker(frame)
    emotion, confidence = analyze_emotion(facial_landmarks)
    gaze_target = calculate_eye_gaze(facial_landmarks)

    # 2. Adaptive Behavior Strategy
    if emotion == "STRESSED" or emotion == "DISTRACTED":
        reduce_stimuli()
        execute_calming_motion()
        speak_audio("Let's take a deep breath.")
        log_progress_event(event="Stress Detected", value=confidence)

    elif gaze_target == "ROBOT_FACE":
        # Positive Shared Attention Reward
        display_happy_face()
        log_progress_event(event="Shared Attention Held")
