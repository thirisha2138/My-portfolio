This project presents an Automated Part Traceability & Data Synchronization (APTDS) system designed for modern manufacturing environments. The system integrates:

  • AI-based vision for part identification
  • Mechanical conveyor and actuation system
  • ERP-based data synchronization

👉 It combines CAD design, mechanical system integration, and AI-based automation to improve manufacturing accuracy and workflow efficiency.

Problem Statement

Manufacturing industries face significant challenges such as:

  • Errors in manual labeling.
  • Poor traceability of components.
  • Lack of real-time synchronization.
  • Inefficient workflow between stations.
👉 Additionally, these environments typically suffer from:
  • close No proper mechanical validation system
  • close No automated inspection + sorting mechanism

Working Principle

  1. Part moves on conveyor (mechanical system)

  2. Camera captures image (positioned via CAD design)

  3. AI model detects part type & system validates part

  4. If valid → conveyor moves forward + label printed
    If invalid → system stops / rejects part

  5. Data is synchronized with ERP system

👉 This highlights the tight coupling between mechanical motion and AI decision-making.
