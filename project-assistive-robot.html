The Challenge

Designing a compact, intelligent assistive robot that can operate autonomously in indoor environments required solving multiple engineering challenges:

  • Real-time object & face detection on low-power hardware.
  • Smooth robotic arm control with 5 DOF.
  • Natural human-robot interaction using voice commands.
  • Reliable navigation and obstacle avoidance.
  • Efficient power management with a custom battery system.

arrow_forward Core problem: How to integrate vision, voice, and motion into a single low-cost, real-time robotic system?

from ultralytics import YOLO
import cv2

# Load YOLOv8 model for real-time object detection
model = YOLO('yolov8n.pt')

def process_frame(frame):
    # Run inference on the camera frame
    results = model(frame, stream=True)
    
    for r in results:
        boxes = r.boxes
        for box in boxes:
            x1, y1, x2, y2 = box.xyxy[0]
            cls = int(box.cls[0])
            
            # Identify specific user items like a mobile phone
            if model.names[cls] == 'cell phone':
                print("[INFO] Target detected.")
                trigger_pick_and_place(x1, y1, x2, y2)
                
    return frame

System Architecture & Results

Dual-layer architecture: High-level AI processing handled by Raspberry Pi. Low-level control managed by Motor drivers & servo controllers. Sensor fusion uses Camera + Ultrasonic via GPIO, I2C, and UART.

🧪 Performance & Results

  • Successfully detected People and Objects (cell phone, chair, etc.) in dynamic environments.
  • Achieved real-time face recognition.
  • Completed pick-and-place tasks accurately without losing balance.
  • Fully assembled working prototype operating continuously with stable robotic arm control.
